Why this project

A small, focused classifier

Built as a deep learning exercise in image classification — simple to run, easy to understand, and genuinely useful for quick identification.

CNN classification

A convolutional neural network trained on labeled imagery predicts the most likely class with a confidence score for every category.

Instant facts

Once classified, the app looks up the object on Wikipedia and surfaces a summary plus key statistics like mass and diameter.

Reverse image search

Want to dig deeper? Jump straight into a Google reverse image search for the photo you uploaded.
