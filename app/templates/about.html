About this project

Classification of Celestial Bodies using a CNN

A deep learning project that trains a convolutional neural network to recognize planets, our Moon, asteroids, and galaxies from a single image, then enriches the result with facts pulled live from Wikipedia.

View the source code on GitHub

12 classes

Eight planets, the Moon, asteroids, and spiral & elliptical galaxies.

Open source

Built with Flask, TensorFlow, and Keras. The full codebase is free to explore and reuse.

Learning project

Created as a hands-on exercise in applying CNNs to a real-world image classification task.
